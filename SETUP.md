# Setup
1. Create a public repo named exactly your username, with a README.
2. Upload the contents of this folder: `README.md`, `assets/hero.svg`, `.github/workflows/snake.yml`.
3. Replace `USERNAME`, `YOUR NAME`, `YOUR-HANDLE`, the email, and the project names in `README.md`. Change the typed lines at the bottom of `assets/hero.svg` if you like.
4. Snake (optional): repo > Actions > "contribution snake" > Run workflow. It publishes `snake.svg` to an `output` branch. If you skip it, delete the snake `<img>` in the README.
